# Cortext Architecture Specification

## 1. Role & Identity
Cortext is a sovereign, local, headless cognitive working-memory daemon for Linux.
It intercepts `/v1/chat/completions` requests from local frontends (Aether OmniBar, CLI pipes, editors), resolves relevant entity subgraphs from an embedded SQLite graph, injects a deduplicated context delta into the prompt, and proxies the call to a chosen frontier LLM.

## 2. Storage Schema (`~/.config/cortext/memory.db`)
Using `aiosqlite` and `sqlite-vec`:

1. `entities`:
   - `id` INTEGER PRIMARY KEY AUTOINCREMENT
   - `name` TEXT UNIQUE NOT NULL
   - `archetype` TEXT NOT NULL (person, project, system, vehicle, concept)
   - `summary` TEXT DEFAULT ''
   - `metadata` JSON DEFAULT '{}'
   - `origin` TEXT NOT NULL DEFAULT 'user_explicit' ('user_explicit', 'model_inferred', 'system')
   - `confidence` REAL NOT NULL DEFAULT 1.0 (0.0-1.0; higher confidence wins on upsert, user_explicit is never displaced at equal confidence; resolver tags < 0.8 as `[inferred]`)
   - `created_at`, `updated_at` DATETIME
   - `access_count` INTEGER NOT NULL DEFAULT 0 (times recalled into a context delta; migrated onto older DBs)
   - `last_accessed_at` DATETIME (NULL until first recall; set by `touch_access`)

2. `edges`:
   - `id` INTEGER PRIMARY KEY AUTOINCREMENT
   - `source_id` INTEGER NOT NULL (FK -> entities.id)
   - `target_id` INTEGER NOT NULL (FK -> entities.id)
   - `relation` TEXT NOT NULL
   - `weight` REAL NOT NULL DEFAULT 1.0
   - `metadata` JSON DEFAULT '{}'
   - `origin` TEXT NOT NULL DEFAULT 'user_explicit' ('user_explicit', 'model_inferred', 'system')
   - `confidence` REAL NOT NULL DEFAULT 1.0 (0.0-1.0; higher confidence wins on upsert, user_explicit is never displaced at equal confidence; resolver tags < 0.8 as `[inferred]`)
   - `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP (migrated onto older DBs; bumped on deprecation and winning upserts)
   - `access_count` INTEGER NOT NULL DEFAULT 0 and `last_accessed_at` DATETIME (same semantics as on entities; migrated onto older DBs)
   - UNIQUE(source_id, target_id, relation)
   - Deprecation: a severed edge is never deleted; it keeps its row with `weight = 0.0`, `confidence = 0.0`, `metadata.deprecated = true` and `metadata.deprecation_reason`.

3. `episodes`:
   - `id` INTEGER PRIMARY KEY AUTOINCREMENT
   - `timestamp` REAL NOT NULL
   - `session_id` TEXT NOT NULL
   - `narrative` TEXT NOT NULL
   - `extracted_entities` JSON DEFAULT '[]'
   - `compacted_at` DATETIME (NULL until session compaction processes the episode; migrated onto older DBs)

4. `entity_embeddings`:
   - `entity_id` INTEGER PRIMARY KEY (vec0 virtual table, float[384]); written by `upsert_entity(embedding=...)`, queried by `find_similar_entities` (KNN, L2 distance) for the resolver's semantic tier, deleted with the entity.

## 3. Module Directory (`src/cortext/`)
- `db.py`: `DatabaseManager` (aiosqlite). Opens the DB, loads `sqlite-vec`, applies `PRAGMA journal_mode=WAL`, `synchronous=NORMAL`, `foreign_keys=ON`, `busy_timeout=5000`, creates schema DDL (incl. `entity_embeddings` vec0 float[384]) and runs column migrations. Enforces POSIX modes at runtime: parent dir `0700`, DB/`-wal`/`-shm` files `0600` (chmod errors from non-owners are ignored). Provides `touch_access(entity_ids, edge_ids)` (one transaction; `access_count += 1`, `last_accessed_at = CURRENT_TIMESTAMP`; duplicate ids count once, empty lists are a no-op), `deprecate_edge(source, target, relation, reason="deprecated")` (entity ids or names; canonical names and `metadata.aliases` resolve; relation casefolded; sets weight/confidence 0.0 and `metadata.deprecated`/`deprecation_reason`, bumps `updated_at`, keeps the row; returns False when no active matching edge exists; a later winning `upsert_edge` of the same triple revives it), `get_entity_subgraph(..., active_only=False)` (when true, deprecated edges are neither returned nor traversed), `upsert_entity` (an optional 384-float embedding replaces the row in `entity_embeddings`, only when the assertion wins on provenance), `upsert_edge` (confidence/origin precedence), `find_similar_entities(query_embedding, limit=5, distance_threshold=1.0)` (sqlite-vec KNN, L2 distance: `WHERE embedding MATCH ? AND k = ? ORDER BY distance`, keeps `distance <= threshold`, returns entity ids nearest first), `find_duplicate_entity(name, archetype, summary, distance_threshold=0.45)` (case-insensitive exact name/`metadata.aliases` match, then vector KNN restricted to the same archetype; string-only when vectors or the embedder are unavailable), `merge_entity_alias(id, alias, summary, origin, confidence)` (appends a de-duplicated alias, fills an empty summary, applies confidence by provenance precedence, always bumps `updated_at`), `upsert_entity_deduped` (find + merge, else plain `upsert_entity`), `get_entity_subgraph`, `record_episode`. Dropping an entity (`cli.py`) also deletes its `entity_embeddings` row.
- `embed.py`: `Embedder` protocol (`embed(text) -> list[float]`) and `EmbeddingManager`, a `fastembed.TextEmbedding` wrapper (default `BAAI/bge-small-en-v1.5`, 384 dims, matching `entity_embeddings`). `fastembed` is imported and the model built lazily on first `embed`, so imports, the CLI and tests never pay load cost. A `model_factory` or any custom `Embedder` can be injected for offline tests; wrong-dimension output raises `ValueError`.
- **Embedder wiring:** `daemon.build_app` builds one lazy `EmbeddingManager` and shares it with `ContextResolver(..., embedder=...)` (semantic tier) and `DatabaseManager(..., embedder=...)`, so daemon startup stays fast. When a `DatabaseManager` has an embedder and `upsert_entity` gets `embedding=None`, it embeds `f"{name}: {summary}"` (just `name` when the summary is empty; see `db.embedding_text`) off the event loop; an embedder failure is logged and never blocks the write. An explicit `embedding` always wins. `cortext embed-backfill` (`cli.py`) embeds every entity with no `entity_embeddings` row using the same text format and reports the count; re-running it is a no-op.
- `extractors.py`: Model B. `LLMExtractor(base_url, model_name, api_key="ollama")` is an async `Extractor` (`(query, response) -> extraction`) for `DistillationEngine`. It POSTs to a local OpenAI-compatible `{base_url}/chat/completions` (Ollama, vLLM) with a concise system prompt demanding strict JSON: `entities` (name, archetype, summary) , `edges` (source, target, relation) and `deprecated_edges` (source, target, relation, reason; emitted only when the user explicitly says a relationship ended, was replaced, sold, stopped or invalidated) plus optional `forgotten_entities` (list of names; emitted only when the user explicitly commands the system to forget, delete, scrub or erase an entity, and never also listed as an entity or edge endpoint). `parse_extraction` defaults `forgotten_entities` to `[]` when missing or malformed. `parse_extraction` tolerates code fences and surrounding prose, drops malformed items, and any transport error, non-2xx status or unparsable JSON yields empty lists, so the exchange is still recorded as an episode. Output flows through the normal ingestion defenses (sanitization, grounding, provenance: `model_inferred` at 0.6, edge requirement). `daemon.build_app` uses it only when `extractor_model` is set (URL defaults to `http://127.0.0.1:11434/v1`); otherwise `heuristic_extract` stays the default. Distillation is a background task, so SLM latency never delays the proxied reply.
- `config.py`: Frozen `Config` dataclass. Resolution per field: env var > `~/.config/cortext/config.json` > default. Keys: `decay_enabled` (bool, default `false`, `CORTEXT_DECAY_ENABLED`), `decay_half_life_days` (float, default `30.0`, `CORTEXT_DECAY_HALF_LIFE_DAYS`; fractional days allowed), `upstream_url`, `upstream_api_key`, `api_key`, `host`, `port`, `db_path`, `log_level`, `socket_path`, `extractor_model`, `extractor_url` (both default empty), `distance_threshold` (float, default `1.0`, max L2 distance for semantic matches), `dedup_distance_threshold` (float, default `0.45` ~ cosine 0.90, max L2 distance for merging a candidate entity into an existing one at ingestion; env `CORTEXT_DEDUP_DISTANCE_THRESHOLD`, config.json `dedup_distance_threshold`; passed by `daemon.build_app` to `DistillationEngine`) (env: `CORTEXT_<KEY>`). Defaults: host `127.0.0.1`, port `8088`, upstream `https://api.openai.com/v1`, `socket_path` empty. Transport detection (`effective_socket_path`, `is_socket_mode`, `get_bind_target`): explicit `socket_path` selects UDS; else UDS at `$XDG_RUNTIME_DIR/cortext/cortext.sock` when `XDG_RUNTIME_DIR` is set and host/port were not set via env or config.json (`tcp_explicit`, excluded from equality); else TCP. A malformed file is ignored on load. `save_config_value` writes atomically (temp file + `os.replace`, mode `0600`). Secret masking is performed by `cli.py` (`mask_secret`), not here.
- `daemon.py`: Entrypoint (`python -m cortext.daemon`). `build_app` wires `DatabaseManager`, `SessionLedger`, `ContextResolver`, `create_app`. `main` loads config, starts logging, then serves in socket mode or TCP mode (Section 5). Socket lifecycle: `prepare_socket` (parent dir `0700`, stale socket unlinked), uvicorn serves on `uds`, socket chmod `0600` once bound, socket unlinked on shutdown. TCP mode uses `uvicorn.run(host, port)`. uvicorn traps SIGINT/SIGTERM and runs the FastAPI lifespan: startup connects SQLite; shutdown drains distillation tasks, closes the HTTP client, closes SQLite.
- `proxy.py`: FastAPI streaming proxy: `GET /health` (open readiness probe) and `POST /v1/chat/completions`. Resolves a session delta from the last user message and prepends it to the first system message (or inserts one). Streams SSE upstream responses through unchanged. Optional constant-time inbound Bearer auth on `/v1/*` (Section 4). Reads `X-Cortext-Allow-Private` for egress scoping. Session id: body `session_id` > `X-Session-Id` header > `default`. Schedules background distillation after a successful exchange. On upstream failure it rolls back the session ledger (Section 6); there is no automatic upstream retry, the client retries and receives the full context again.
- `resolver.py`: `ContextResolver`. `match_entities` does an exact whole-word scan of entity names and `metadata.aliases` (casefolded), then a constituent-token fallback, then (only if an `embedder` is injected and fewer than `max_entities` matched) a vector-KNN tier via `db.find_similar_entities`. Matching invariant: Exact Whole-Word -> Constituent-Token -> Vector KNN; semantic hits only fill remaining slots, never displace lexical ones, are filtered by the same `allow_private` rule, and are skipped entirely (no embedding call) when the lexical tiers already fill `max_entities`. `gather` walks the graph 1 to 2 hops (`MAX_HOPS_LIMIT = 2`). `resolve` returns a markdown block of facts new to the session. Facts with confidence < 0.8 are tagged `[inferred, confidence: x.xx]`. Private entities are scoped out unless allowed (Section 4). Defaults: `max_entities=5`, `edge_limit=10`. Semantic matching uses sqlite-vec default **L2 (Euclidean)** distance, not cosine: unit vectors at cosine distance ~0.35 sit at L2 ~0.83, orthogonal noise at L2 >= 1.414. `distance_threshold` (default `1.0`, wired from `Config.distance_threshold` by `daemon.build_app`) keeps hits with `distance <= threshold`.
- `distill.py`: `DistillationEngine.process_exchange`: sanitize, substantive-turn gate, heuristic extraction (or injected extractor), grounding, persistence, episode record. Failures are logged, never raised. Conversational forgetting: `heuristic_extract` detects explicit "forget/erase/scrub <Name>" and "delete entity/note/record <Name>" commands (never "don't forget") into `forgotten_entities`; `process_exchange` first resolves each name through `db.find_entity` (canonical name, then unambiguous `metadata.aliases`), calls `db.drop_entity`, evicts the id from the optional `SessionLedger`, logs `User-directed forgetting: dropped entity '<name>' (id=<n>)` at INFO, discards same-extraction entities/edges/deprecations that reference the forgotten names, and appends `forgotten=N` to the episode log line when non-zero. Enforces the edge requirement and constituent consolidation (Section 6). `strip_markdown_structure` removes heading lines and bold labels so formatting words never become entities. All token/stop-word rules live in `stopwords.py` (`distill.py` keeps no private stop-word list). Edge validity (non-empty fields, no self-loop, valid names, no secrets) is defined once in `_valid_edge` and shared by the edge-requirement check and edge persistence; heuristic and injected extractors (e.g. `LLMExtractor`) go through the same `process_exchange` pipeline.
- `sanitize.py`: `sanitize_text` replaces matches with `[REDACTED_SECRET]` for: PEM private key blocks, URIs with embedded credentials (DB URIs), JWTs, `Bearer` tokens, GitHub (`ghp_`, `github_pat_`), OpenAI-style `sk-`, Google `AIza`, AWS `AKIA`. `is_secret_token` flags candidate entity names that are redaction-affected or are high-entropy: length >= 24, no whitespace, contains letters and digits, Shannon entropy >= 3.5 bits/char.
- `stopwords.py`: Stop-word and filler lists, `is_valid_entity_name` (rejects stop-words/fillers; short names allowed via whitelist), `name_tokens`. Also used by the resolver to skip single-word stop-word concepts.
- `session.py`: `SessionLedger`: in-memory, per-session `seen_entity_ids` and `seen_edge_ids` (separate id spaces), idle TTL 3600 s, `filter_new` returns a `SessionDelta`, `reset`, `evict_expired`, `evict_entity(entity_id)` (removes an id from every session so a forgotten entity is treated as gone). Single event loop only; not persisted.
- `logging.py`: `cortext` logger tree. `RotatingFileHandler` (5 MiB, 2 backups) at `~/.local/share/cortext/cortext.log` (override `CORTEXT_LOG_PATH`). Directory forced to `0700`, log file to `0600` (re-applied after each rollover). Stderr stream only in debug on a TTY.
- `compactor.py`: `SessionCompactor(db, extractor_url, extractor_model, threshold_hours=24.0)`. `compact_session(session_id)` loads uncompacted episodes (returns immediately when none), sanitizes narratives, asks the local SLM (or a heuristic when `extractor_model` is empty) for `{"entity_summaries": [{"name", "summary"}], "session_summary"}`, updates matching `entities.summary` via `db.update_entity_summary` (provenance-gated; SLM at `model_inferred` 0.6, heuristic at 0.5), then calls `db.mark_episodes_compacted`. `compact_all(older_than_hours=None)` compacts eligible sessions sequentially and returns the count. It never raises. DB methods: `get_uncompacted_sessions(older_than_seconds)` (distinct session ids whose newest uncompacted episode is older than the cutoff), `get_session_episodes(session_id, uncompacted_only=True)`, `mark_episodes_compacted(ids)` (`compacted_at = CURRENT_TIMESTAMP`), `update_entity_summary(name, summary, origin, confidence)`. Config: `compaction_threshold_hours` (default `24.0`, `CORTEXT_COMPACTION_THRESHOLD_HOURS`).
- `cli.py`: `cortext` operator tool (`[project.scripts]`), global `--db`. Commands: `stats`, `list [--archetype --limit]`, `inspect <name|id>`, `drop <name|id> [-y]`, `prune-stale [--confidence-below X]` (default 0.5, removes model_inferred facts), `compact [--hours FLOAT] [--session TEXT]` (compacts inactive sessions, or one named session regardless of age; prints `Compacted session 'X' (N episodes, M summaries updated)`), `config show|get|set` (`show` masks secrets), `logs [-n N]`.

## 4. Security & Privacy Architecture
- **POSIX storage isolation:** data and log directories `0700`; DB, WAL, SHM, log files and `config.json` `0600`. Applied at runtime by `db.py`, `logging.py`, `config.py`, not left to umask.
- **Inbound auth:** if `CORTEXT_API_KEY` (or `api_key` in config.json) is non-empty, every `/v1` and `/v1/*` request must send `Authorization: Bearer <key>`. It is compared with `hmac.compare_digest` and failure returns 401 `authentication_error`. `/health` is always open. If the key is empty, auth is disabled. The inbound key is distinct from `CORTEXT_UPSTREAM_API_KEY`. The upstream key, when set, is the only credential sent upstream. The client's `Authorization` header is forwarded only when neither key is configured.
- **Ingestion defense:** query and response pass through `sanitize_text` before substantive-turn gating, extraction and `record_episode`, so redacted text is what is stored. Entity names and edge endpoints that satisfy `is_secret_token` are dropped. The entropy heuristic applies to candidate names/endpoints only; free text is covered by the regex patterns.
- **Egress guardrails:** an entity is private if `archetype == 'private'` or `metadata['private'] is True`. Private entities, and edges touching them, are excluded from the delta and from graph traversal unless the request sends `X-Cortext-Allow-Private: true` (case-insensitive). The default is no private data to the LLM.

## 5. Transport
- **Desktop mode (UDS):** zero-network local IPC at `$XDG_RUNTIME_DIR/cortext/cortext.sock` (mode `0600`, parent dir `0700`), or any path given by `CORTEXT_SOCKET_PATH`.
- **Server/container mode (TCP):** `CORTEXT_HOST:CORTEXT_PORT`, chosen whenever host or port is set explicitly or `XDG_RUNTIME_DIR` is absent. The Docker image sets `CORTEXT_HOST=0.0.0.0`, so it uses TCP.
- **TCP details:** Served by uvicorn on `CORTEXT_HOST:CORTEXT_PORT` (default `127.0.0.1:8088`). Use this for Docker/remote deployments, with `CORTEXT_API_KEY` set when binding beyond loopback.
- **UDS details:** socket lifecycle is in the `daemon.py` entry (Section 3). systemd uses `RuntimeDirectory=cortext` and `%t/cortext` in `ReadWritePaths`.

## 6. Operational Invariants
- **Edge requirement:** a `model_inferred` entity persists only if it is an endpoint of at least one valid edge in the same extraction (valid = non-empty source/target/relation, not a self-loop, valid names, no secrets). Otherwise it is dropped. `user_explicit` entities are exempt.
- **Compaction:** only sessions whose newest uncompacted episode is older than the threshold are compacted (`--session` bypasses the age check). Episodes are never deleted, only stamped `compacted_at`, and are stamped only after the summary step succeeds, so a session is compacted at most once and retried if the SLM fails. Compaction summaries obey provenance: they never displace a higher-confidence summary, nor a `user_explicit` one at equal confidence, and keep the stored origin/confidence. SLM output is sanitized and capped at 300 chars per summary; unknown entity names are ignored.
- **Provenance:** extractions without attribution are `model_inferred` at confidence 0.6. On upsert, higher confidence wins and `user_explicit` is never displaced at equal confidence.
- **Upstream failure rollback:** since facts are marked seen when resolved, any upstream failure (connect/send error, status >= 400, body-read error, stream interrupted mid-relay) calls `ledger.reset(session_id)` so the next request replays the full context. Failed or interrupted exchanges are never distilled.
- **Alias matching:** exact = casefolded whole-word match of the entity name or any `metadata.aliases` entry (word boundary enforced only on word-character edges, so `C++` matches). Constituent = whole-word match of a single token of a name/alias (>= 3 chars, not a stop/function word). Ranking: confidence desc, exact before constituent, first mention, id.
- **Constituent consolidation (write side):** a single-word candidate with no entity of its own that equals an alias or token of exactly one multi-word entity (`BMW` -> `BMW 540i`) refreshes that entity's `updated_at` instead of creating a node. Ambiguous matches are not consolidated.
- **Dedup / alias merge gate (write side):** before `DistillationEngine` inserts a candidate entity it calls `db.find_duplicate_entity`. A candidate equal (casefolded) to an existing entity name or `metadata.aliases` entry resolves to that entity; otherwise, when vectors are enabled, the nearest entity within `dedup_distance_threshold` (L2 <= 0.45) with the **same archetype** is the canonical entity (a `system` never merges into a `concept`). A merge inserts no row: the candidate name is appended to `metadata.aliases` (no duplicates), an empty summary is filled from the candidate, confidence/origin follow the provenance precedence above, and `updated_at` is bumped so `ContextResolver`'s alias scanner recognizes the alias on the next recall. Every edge in the same extraction that named the candidate is wired to the canonical entity id. Without sqlite-vec or an embedder only the exact/alias string check applies. An exact-name hit is a normal upsert, not a merge.
- **Edge deprecation (contradiction resolution):** `DistillationEngine` processes `deprecated_edges` after entities and active edges, mapping endpoints to canonical ids (names merged/consolidated this turn, else db alias resolution) and calling `db.deprecate_edge`; each deprecation logs at INFO. Episodes are never altered. `ContextResolver.gather` requests `active_only` subgraphs and also drops any edge with `weight <= 0.0`, `confidence < 0.2` or `metadata.deprecated is True`, so deprecated edges are never traversed or injected. The heuristic fallback detects basic negation (`I sold X`, `I no longer use X`, `I stopped using X`) as a `User -> X` deprecation; otherwise `deprecated_edges` is empty.
- **Temporal access decay & reinforcement:** `ContextResolver.resolve` calls `db.touch_access` for every entity and edge id gathered into the context (including facts already seen this session, so active knowledge stays reinforced); a touch failure is logged and never blocks recall. With `decay_enabled = false` (default) ranking is the legacy `confidence * weight` (entities: confidence first, then match tier/position) and nothing is pruned. With it enabled, `resolver.effective_priority` = `confidence * weight * decay_factor * frequency_factor`, where `delta_days = (now - (last_accessed_at or created_at)).total_seconds() / 86400.0` (edges fall back to `updated_at`), `decay_factor = 2.0 ** (-max(0.0, delta_days) / decay_half_life_days)` and `frequency_factor = min(1.5, 1.0 + 0.05 * access_count)` (entities have weight 1.0). Matched entities are sorted by effective priority (then match tier, first mention, id), subgraph edges by hop, then effective priority, and any entity or edge below `0.15` is pruned. Facts without a usable timestamp are treated as fresh.
- **Conversational forgetting:** user-directed forgetting is a permanent hard delete like `cortext drop`: `db.drop_entity(id)` removes the entity, every edge touching it and its `entity_embeddings` row (when vectors are active) in one WAL transaction. Names resolve by casefolded canonical name or an alias that identifies exactly one entity; an ambiguous or unknown name is a logged no-op that never raises, and the episode is still recorded. A forgotten entity (and its aliases) is never re-created or linked by the same extraction, and is evicted from active `SessionLedger` sessions (`DistillationEngine(ledger=...)`, wired by `daemon.build_app` and `proxy.create_app`). Only the user's explicit command triggers it; model-inferred forgetting is not supported.
- **Turn gating:** trivial exchanges (short greeting/acknowledgment queries without a fact assertion, empty or boilerplate replies) are not distilled.

## 7. Graceful Degradation & Diagnostics
- **Embedder fallback:** `embed.create_embedder()` returns a lazy `EmbeddingManager`, or `None` when `fastembed` is not installed (logs `[WARNING] [embed] fastembed unavailable; falling back to lexical-only matching.`). `daemon.build_app` passes it straight to `ContextResolver(..., embedder=...)`, so a `None` embedder means lexical-only mode. If the lazy import or model load fails (corrupt install, offline weights), `EmbeddingManager` logs the same warning once and raises `EmbeddingUnavailable` on every later call; the resolver treats that as "no semantic hits", `DatabaseManager` writes without an embedding, and `embed-backfill` exits 1 with a message.
- **sqlite-vec fallback:** if the extension fails to load, `DatabaseManager.connect` logs `[WARNING] [db] sqlite-vec extension failed to load; vector indexing disabled.`, skips creating `entity_embeddings`, and sets `vec_enabled = False`. Entities, edges and episodes work normally; embedding writes, auto-embedding, `find_similar_entities` (returns `[]`) and the resolver's semantic tier are skipped; `cortext drop` skips the vector delete; `embed-backfill` exits 1.
- **Compaction fallback:** if the extractor SLM is unreachable, errors, or returns unparseable JSON, `SessionCompactor` logs `[WARNING] [compactor]` and skips the session, leaving its episodes uncompacted; `cortext compact` prints a `Skipped session` line and still exits 0.
- **`cortext doctor`** (`cli.py`): prints a checklist (`[ok]`, `[warn]`, `[fail]`) for DB path and journal mode, sqlite-vec status, fastembed install and model cache (`$FASTEMBED_CACHE_PATH` or `<tmp>/fastembed_cache`), extractor SLM reachability (`GET {extractor_url}/models`, timeout 0.5 s; a failure is `[fail]` only if `extractor_model` is configured), and the active transport (UDS path or TCP host:port). It always exits 0.
